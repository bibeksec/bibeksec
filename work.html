Sentinel Detect

A Python tool that reads Linux SSH authentication logs, finds suspicious login patterns and produces severity-ranked alerts.

  1. auth.log
  2. Parser
  3. Detector
  4. Severity scoring
  5. CSV / JSON report

PythonRegular expressionsCSV and JSON outputLinux auth logs

Read the case study

Problem. SSH logs are long and repetitive, so suspicious login patterns are easy to miss.

Approach. Parse each line with regular expressions, group logins by source, flag unusual patterns and score each alert by severity.

Output. CSV and JSON reports.

Status. In progress.
