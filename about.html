Profile

I’m Bibek Raj Tamata, from Nepal. I study how systems are designed, where their assumptions fail, and how to fix them.

Technical approach

Understand the system first. Then test one assumption at a time in a lab, record what happened, and write the fix next to the finding.

Education

Bachelor of Information Technology (BIT) student.

Current learning focus

Web application security through PortSwigger-style labs, and Python scripts that automate log analysis.

Interests

Application security, vulnerability research, Python automation, OSINT, network security, defensive security, reverse engineering, digital forensics and AI security.

Career direction

Application security and security engineering, with room to discover which specialty fits best.

Toolkit

Python, C++, Linux, Git, Docker, Nmap, Burp Suite, Wireshark, Nessus, Metasploit, ffuf and Gobuster.

Ethics

I only test systems I own or am authorized to assess. I use intentionally vulnerable labs, and I report issues responsibly.
